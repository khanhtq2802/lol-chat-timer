Mouse Button Reaction Test

Two tests: Test 1 measures the pure reaction time of each button and finger; Test 2 measures moving the cursor to a target and then pressing the right button (like an aim trainer). Supports left/right click, wheel click, Back/Forward, scroll up/down, and keyboard keys (if you have remapped mouse buttons to keys in G HUB).

InputFinger (note)
Press any button to check that the browser detects it.

2. Test 1: Button reaction

On: you know which input to press and only wait for the signal, so it measures pure finger speed. Use this mode to compare fingers. Off: the input is revealed at random, so it also measures recognition and choice time (closer to a real fight).

  • A red screen means wait; when it turns green, press the shown input as fast as you can.
  • Pressing while waiting, or faster than 100 ms, counts as a false start and that trial is repeated.
  • Press Esc to stop at any time.
  • Each result may be off by about one display frame, but the error is the same for every input, so comparisons stay valid.

3. Test 2: Move + press

A round target appears at a random position, with a mouse picture highlighting the input to use. Move the cursor onto the target, then press that exact input (for scrolling: scroll while the cursor is inside the target). Uses the inputs chosen in section 1.

  • Pressing outside the target is a miss; pressing the wrong input inside it is a wrong input. Both cost 1 point and the target stays.
  • Results split move time (target appears → cursor reaches it) and press time (cursor enters target → press).
  • Use "No limit" for accurate measurement; enable shrinking to practise under time pressure.
